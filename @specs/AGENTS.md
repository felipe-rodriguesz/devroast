# Specs

## When
Criar spec antes de implementar nova feature.

## Format

```md
# Feature: [nome]

## Goal
[1-2 linhas do que a feature faz]

## UI/UX
[Descrição visual - 参考 Pencil design se disponível]

## Data
- Input: [dados de entrada]
- Output: [dados de saída]

## Tech
- [teca/stack necessária]
- [dependências]

## Steps
1. [step 1]
2. [step 2]
```
